## BLOCKER

### B1：`$(` 前缀会豁免整个密码捕获值，放过命令替换之外的明文密码

**位置：** [rules.go:61](../../internal/secrets/rules.go#L61)；受影响的附加判断为 [url_credentials:36](../../internal/secrets/rules.go#L36) 和 [generic_assignment:50](../../internal/secrets/rules.go#L50)。

`envReference` 中的 `\$\(.*` 分支只要求捕获值以 `$(` 开头，不检查命令替换是否闭合，也不限制后续字面量。`url_credentials` 和 `generic_assignment` 将这个判断作用于整个捕获的密码；一旦判定为引用，就跳过正常的密钥判断。

以下使用合成密码的反例已通过公开的 **`secrets.New → Scanner.JSON → secrets.Reject`** 调用链独立复现。探针中的密码由 `"s3cr3t" + "Pass9"` 在运行时拼接。

| 输入 | 实际结果 |
|---|---|
| `password=s3cr3tPass9` | 拒绝，正向对照成立 |
| `password=$(true)s3cr3tPass9` | 错误放行 |
| `postgres://app:$(true)s3cr3tPass9@db/app` | 错误放行 |
| `password=$(s3cr3tPass9` | 错误放行 |

URL 反例也先验证了不带该前缀的 URL 密码能够被拒绝。三个新增子测试均在“应拒绝”的断言上失败，实际的拒绝结果为 `nil`；测试没有停留在私有豁免辅助函数上。

完整命令替换之后的明文后缀仍被整体豁免。这个反例超出了此前接受的“命令替换内部普通密码字面量可能漏报”范围，也违反本轮明确要求的 `$()` 安全边界。`$()` 可表示命令替换或子表达式，不能仅凭这个前缀把整个捕获值视为安全的环境变量引用。

**影响：** 检测模块对本可识别的密码返回无命中。将来直接接入写入流程，会允许敏感文本通过检测。目前尚未接入业务写入，因此本轮没有证明已经发生数据库泄露。

**最小修复：**

1. 删除任意 `$(` 前缀的整体豁免，保留四种完整环境变量引用：`$NAME`、`${NAME}`、`%NAME%`、`$env:NAME`。
2. 继续检查表达式及相邻字面量，不能因为出现命令替换而跳过整个密码捕获值。
3. 同步收窄 [architecture.md:525](../architecture.md#L525)，更正 [boundary_test.go:60](../../internal/secrets/boundary_test.go#L60) 中将命令替换称为环境引用的预期。
4. 为赋值、URL 密码、未闭合前缀增加公开 `JSON`／`Fields` 接口的拒绝反例，同时保留四种环境引用及既有混合、多候选测试。

无需引入完整 Shell 解析器，也无需改动存储层。**本项必须在接受 WP1.3、合并当前 PR 前解决。**

## NON-BLOCKER

### N1：无条件规则仍收集全部匹配，产生不必要的分配

**位置：** [rules.go:80](../../internal/secrets/rules.go#L80)。

`rule.hit` 先调用 `FindAllStringSubmatch(v, -1)` 生成全部子匹配，再遍历并返回第一个命中。对于没有附加条件的内置规则和全部自定义规则，只要存在一次匹配，就已经可以确定结果。

**可验证探针：** 使用合法自定义规则 `{id: "custom_any", pattern: "."}` 扫描 4000 个 `a`。本次进程测得该调用累计分配 **551,552 字节，约 539 KiB**，输入仅 4000 字节。这是累计分配测量，不是峰值常驻内存测量。

**影响：** 输入存在大量短匹配时，会增加临时分配和垃圾回收开销。

**最小修复：** `accept == nil` 时使用 `MatchString`；有附加条件的规则继续检查后续候选，不能改成只检查第一处匹配。

Go 正则的线性时间保证及现有规则数量、长度限制有效，未发现灾难性回溯风险。上述分配优化有实际收益，但不构成当前本地模块的资源耗尽漏洞，也不阻塞合并。
