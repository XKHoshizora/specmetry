**NON-BLOCKER**

1. **片段总量上限的验收项没有同步迁移到 M2。**

   位置：[acceptance-criteria.md:98](../acceptance-criteria.md#L98)、[data-model.md:262](../data-model.md#L262)。

   `MVP-BL-26` 仍要求在 M1 反复提交片段，超过保存总量上限时返回退出码 2；新规则明确该上限只计算保存原文的 `full` 引用，而 M1 只有 `hash_only`。

   **反例：** M1 连续提交合法的 `hash_only` 引用，没有保存任何原文，因此不会达到“已保存原文”的总量上限，却会被现有验收项要求拒绝。

   **影响：** 容易导致错误测试预期，或为了满足测试而引入不必要的累计计数规则。

   **最小修改：** 将 BL-26 标注为 M2、明确 `full` 前置条件；M1 继续验证单片段长度和原文不落盘。此项应在相关验收测试落地前修正，不阻塞 WP1.3 或设计合并。

2. **部分输出 Schema 缺少字段之间的语义约束。**

   在仓库外使用现有验证器，独立确认以下矛盾组合仍能通过：

   | 位置 | 可通过的矛盾组合 |
   |---|---|
   | [proposal-receipt:41](../../schemas/proposal-receipt.v1.schema.json#L41) | Agent 提案 `applied_version=null`，条目却为 `accepted` 并具有已分配编号 |
   | [question-list:52](../../schemas/question-list.v1.schema.json#L52) | 问题为 `answered`，回答动作却是 `dismiss` |
   | [proposal-show:49](../../schemas/proposal-show.v1.schema.json#L49) | `type=goal`，`proposed` 却包含 criterion 的数据 |
   | [status:335](../../schemas/status.v1.schema.json#L335) | 拒收决定的 `snapshot=null`，违反“只有豁免可以没有快照”的说明 |

   **影响：** 输出校验不能发现这些序列化错误，可能误导调用者或审核界面。

   **最小修改：** 在对应输出实现时补充条件约束及反例；跨 ID、数据库状态等无法仅靠 Schema 判断的关系，由输出一致性测试验证。

   这些是**输出约束缺口**，没有构成写入授权或 Ready 推导的绕过路径，因此不列为 BLOCKER。

3. **密钥检测的边界验收还可以更具体。**

   位置：[architecture.md:516](../architecture.md#L516)、[architecture.md:525](../architecture.md#L525)、[acceptance-criteria.md:266](../acceptance-criteria.md#L266)。

   现有样本验证了单个命中与正常环境变量引用，但没有明确覆盖：

   - 同一检查命令同时包含环境变量引用和另一段可识别密钥；
   - 一个字段包含多个候选匹配，前一个被豁免、后一个应被拒绝；
   - 无效自定义正则包含敏感 canary 时，配置错误是否回显原始 pattern。

   **影响：** 实现可能误将环境变量引用作为整字段跳过条件，或直接输出正则编译错误中的原文。

   **最小修改：** WP1.3 增加上述测试。环境引用豁免只作用于对应捕获值；配置错误输出规则 ID 和安全的错误分类，不回显 pattern。当前尚无业务实现，因此这是验收覆盖建议，不是已经确认的运行时漏洞。

**ACCEPTED RISK**

- **例外验收可以计入 Ready。** 这是已批准的 PD-17 边界。理由、快照、`none` 等级和警告有明确要求；之后的执行继续展示，失败仍优先使 AC 进入 `failing`。全部豁免仍不能 Ready。[data-model.md:537](../data-model.md#L537)、[data-model.md:627](../data-model.md#L627)
- **密钥检测是启发式保护。** 14 条规则及附加条件不能覆盖所有秘密。独立探针确认短的纯字母密码、命令替换中的普通密码字面量可能漏报；这符合已批准的“降低风险、不能保证检测所有秘密”边界，不要求重新设计检测体系。[architecture.md:582](../architecture.md#L582)
- **通道识别不是身份认证。** 伪终端、清除环境变量等限制已经如实声明，其他 Agent 的核实安排在 M4，不阻塞当前 M1。[architecture.md:159](../architecture.md#L159)
